# Midnight Precision Portfolio Restyle

## Goal
Apply the selected midnight precision color direction across the portfolio while preserving every existing detail, section order, layout proportion, and image/video size.

## Changes
- Replace the purple-led palette with deep midnight surfaces, crisp indigo-blue accents, and cool neutral text.
- Restyle the hero, navigation, cards, tabs, buttons, badges, borders, shadows, and alternating section backgrounds consistently.
- Improve recruiter scanning through stronger contrast and clearer emphasis on QA evidence, without changing content or structure.
- Add restrained technical polish to hover and focus states while respecting reduced-motion preferences.
- Verify desktop and mobile views, all media dimensions, and the Download CV action.

## Technical details
- Update semantic design tokens and shared gradient/shadow utilities in the global stylesheet.
- Replace remaining component-level legacy purple/white color treatments with semantic token classes where needed.
- Keep all component markup ordering and fixed image/video sizing unchanged.
